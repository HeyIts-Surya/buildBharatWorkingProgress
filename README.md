PMIS Career Copilot — Feature Checklist

1. AI Resume Intelligence
[ ] Upload resume (PDF/DOCX)
[ ] Extract education, skills, experience and projects
[ ] Generate ATS-style resume quality score
[ ] Identify missing or weak resume sections
[ ] Suggest improvements based on internship requirements

2. AI Internship Recommendation Engine
[ ] Recommend internships based on uploaded resume
[ ] Check eligibility against official scheme criteria
[ ] Rank relevant internships using match scores
[ ] Explain why each internship is recommended
[ ] Show missing skills and eligibility gaps
[ ] Filter by location, industry, qualification and interests

3. AI Career Copilot Chatbot
[ ] Answer questions using official PMIS information
[ ] Find internships through natural-language conversation
[ ] Check eligibility and explain application requirements
[ ] Compare multiple internship opportunities
[ ] Explain application status and next steps
[ ] Provide application-related troubleshooting
[ ] Connect with existing email, WhatsApp and support channels

4. AI Commute and Affordability Advisor
[ ] Show internship location and estimated travel distance
[ ] Estimate travel time and transportation costs
[ ] Compare nearby and distant internships
[ ] Estimate practical monthly expenses
[ ] Recommend opportunities based on location preferences

5. Multilingual Voice Assistant
[ ] Accept spoken questions
[ ] Respond using voice
[ ] Support Hindi, English and selected regional languages
[ ] Enable voice-based internship search and navigation

6. Smart Document Assistant
[ ] Upload marksheets and educational certificates
[ ] Extract relevant information using OCR/AI
[ ] Suggest values for application form fields
[ ] Detect missing or inconsistent document information
[ ] Verify certificates through authorized services when available
[ ] Require user confirmation before saving information

7. AI Career Preparation
[ ] Identify skills missing for selected internships
[ ] Recommend free learning resources
[ ] Generate role-specific practice interview questions
[ ] Provide feedback on practice answers

8. Dashboard and Integration
[ ] Add resume upload to the existing candidate dashboard
[ ] Display recommended internships and match explanations
[ ] Integrate an AI Copilot chatbot panel
[ ] Show application guidance and document checks
[ ] Provide reusable API endpoints for existing PMIS services
[ ] Protect personal data and obtain user consent
